# Odin Recipes

A small multi-page recipe website built with plain HTML. It was my first project for practicing page structure and navigation.

## Features

- Home page that links to three recipe pages: pizza, soup, and a smoothie
- Each recipe page has an image, a description, an ingredient list, and steps
- Relative links between pages

## Built With

- HTML

## Run Locally

Clone the repo and open `index.html` in your browser.

Built as part of [The Odin Project](https://www.theodinproject.com/) Foundations course.
